# PA02: JavaScript (Part 2)
# Description
This project adds JavaScript interactivity to a webpage including:
- Form validation
- DOM updates
- Fetch API usage
- Sorting and filtering data

# Technologies Used
- HTML
- CSS
- JavaScript

# How to Run
1. Open index.html in browser
2. Fill out form to test validation
3. Click "Load Users" to fetch data
4. Click "Sort A–Z" to sort results

# Features
- Email validation
- Dynamic list rendering
- Fetch data from API
- Loading / error handling
